This project involved the design, development, and deployment of a full-stack web application for Pizza Basilico, a fictional restaurant. The application was created to provide customers with an intuitive platform for exploring the restaurant, making reservations, and placing takeaway orders, while also giving staff access to tools for managing menu items, bookings, and business information through an administrative dashboard.

Problem Statement

Pizza Basilico lacked a professional digital presence and relied on separate systems for managing reservations, takeaway orders, and restaurant information. This created inefficiencies and made it difficult to maintain a structured workflow.

My Contribution

I was responsible for the entire project, including UX design, frontend, backend, database design, authentication, API development, and deployment.

Solution Overview

The solution consists of a customer-facing website and an administrative dashboard connected through a REST API and MySQL database.

Development Process

Planning & UX/UI

Initial concepts were developed through different methodes such as sitemaps, wireframes, and prototypes. The purpose was to define the structure and user experience.

Sitemap

A sitemap was created to define the structure of the website and organize its content. This helped establish a clear information architecture and ensured that users could easily navigate between different sections of the application.

Wireframes

Wireframes were developed to explore the layout, functionality, and user flow of the application. This made it possible to evaluate the structure and usability of the interface before development began.

Prototype

A prototype was created to visualize the final look and feel of the application. It helped refine the visual design, test interactions, and ensure that the user experience aligned with the project's goals.

System design

The system design phase focused on planning the application's architecture, including the database structure and API communication. This provided a clear technical foundation and ensured that the frontend, backend, and database could work together efficiently.

Database Design

A relational MySQL database was designed to support the application's core functionality, including reservations, takeaway orders, menu management, opening hours, user accounts etc. By structuring the data into related tables, the system could efficiently manage and retrieve information while maintaining data consistency across the application.

ER-diagram

An ER diagram was developed to model the application's data structure and identify relationships between database entities. This provided a clear overview of how information would be stored and connected, serving as a blueprint for the MySQL database implementation.

API Design

The API structure was planned before implementation to establish clear communication between the frontend and backend. RESTful endpoints were developed for key features such as reservations, takeaway orders, menu management, and authentication. Using HTTP methods including GET, POST, PUT, and DELETE, the API enabled CRUD operations on the database.

Development

The application was developed using a full-stack architecture consisting of an Angular frontend, a REST API built with Express, and a MySQL database. The frontend was responsible for presenting data and handling user interactions, while backend managed business logic, authentication, and database operations.

Frontend - Angular

The frontend was developed using Angular to create a dynamic and responsive user experience. A component-based architecture was used to structure the application, while Angular features such as data binding, routing, and HttpClient enabled communication with the backend and the presentation of content from the database.

REST API

A custom REST API was developed using Express to connect the frontend with the database. The API handled core functionality such as reservations, takeaway orders, menu management, and authentication. Through http-request such as GET, POST, PUT, and DELETE, the application was able to perform secure CRUD operations and process user-generated data.

Authentication & Authorization

JWT authentication was implemented to protect sensitive functionality within the application, such as menu management and reservation administration. When an administrator logs in, the backend validates the credentials against stored user data in the database. If the credentials are correct, a JWT token is generated and returned to frontend. This token is then included in future requests, allowing the backend to verify the user's identity and ensure only authorized users can access protected functions.

Architecture

The application was built using a three-tier architecture consisting of an Angular frontend, an Express REST API, and a MySQL database. This architecture separated presentation, business logic, and data management, creating a structured solution that was easier to maintain, develop, and deploy.

Deployment

The application was deployed to make it accessible for users. The frontend, backend, and database were hosted on separate platforms to create a complete production-ready solution.

Frontend Hosting

The frontend was deployed on Netlify, making the application publicly accessible through a live website. This enabled users to interact with the application in a production environment and allowed for continuous updates throughout the development process.

Backend Hosting

The backend was deployed on Render, where it handled API requests, authentication, and business logic. Hosting the backend separately from the frontend created a clean architecture and enabled secure communication with the database.

Database Hosting

The MySQL database was hosted on Railway, providing a cloud-based solution for storing and managing application data. This allowed the application to persist information such as reservations, orders, and user accounts while remaining accessible to the backend.

Potential effects

The solution demonstrates how a restaurant could benefit from a centralized digital platform. By combining reservations, takeaway orders, content management, and administrative functionality, the application could streamline daily operations, reduce manual work, and improve the overall customer experience.
